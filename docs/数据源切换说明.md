# 数据源切换说明（2026-11-09）

## 现在用的是哪个源

行情、日历、代码表、分红从 **a-stock-data**（`simonlin1212/a-stock-data`，Apache-2.0）直连公开接口导出，
不再依赖 BigQuant 平台。导出脚本在本目录：`datadownload/astock_export.py`。

用到的接口（都在那个仓库的 `SKILL.md` 里）：

| 数据 | 来源 | 说明 |
|---|---|---|
| 全市场日行情 | 通达信官网盘后包 `tdx.com.cn/products/data/data/g4day/{YYYYMMDD}.zip` | 一次拿沪深北当日昨收/开高低收/成交量(股)/成交额(元) |
| 交易日历 | 深交所 `szse.cn/api/report/exchange/onepersistenthour/monthList` | `jybz == '1'` 为交易日 |
| 股本（算市值、换手） | 东财快照 `push2.eastmoney.com/api/qt/clist/get` 的 `f20/f2`（总股本）、`f21/f2`（流通股本） | 市值 = 股本 × 当日真实收盘 |
| 分红送转 | 东财 `datacenter-web.eastmoney.com` `RPT_SHAREBONUS_DET` | 每 10 股口径，落盘换成每股 |
| ST/*ST | 东财风险警示板名单 | `st_status`：ST=1、\*ST=2 |

**这些源一律不走代理**：走 127.0.0.1:7890 时通达信的 TLS 握手会被掐断（`SSL: UNEXPECTED_EOF_WHILE_READING`），
脚本内部对国内域名显式 `ProxyHandler({})`。

## 每天怎么更新

```bash
# 收盘后补当天（只写当月/当年分片，不碰历史分片）
python datadownload/astock_export.py --date 2026-11-06 --root /home/agent/data/smallquant/data

# 补一段（断更后的回填；按交易日历逐日拉盘后包）
python datadownload/astock_export.py --start 2026-10-08 --end 2026-11-06 --root /home/agent/data/smallquant/data
```

- 月度分片（`cn_stock_real_bar1d`、`cn_stock_bar1d`、`cn_stock_prefactors`）按 `YYYYMM.parquet` **整月合并重写**，
  所以同一个月反复跑是幂等的，不会重复行。
- 年表（`trading_days`、`cn_stock_dividend`、`cn_stock_instruments`）按年重写。
- 写盘前统一把 `object` 列转成字符串：旧 BigQuant 快照的 `report_date` 是整数（20260930），
  新导出是 `'YYYY-MM-DD'`，混在一起 pyarrow 会按 int 推断后报
  `ArrowTypeError: object of type <class 'str'> cannot be converted to int`。

## 和旧快照对得怎么样（2026-11-04，5,632 只）

| 项 | 结果 |
|---|---|
| 收盘/昨收/开高低 | 5,574 只全部一致（中位与最大偏差都是 0） |
| 成交额 | 5,572 / 5,574 完全相等 |
| 成交量 | 5,568 / 5,574 相等；6 只差异全在北交所 4 只与深市 2 只，比值是 10 或 100 的整数倍（旧快照对北交所用"股×10"或"手"的口径） |
| 总市值 | 300 只抽样最大相对偏差 4.3%，中位 0.0%（差异来自旧快照用实时价、这里用当日收盘） |
| 交易日历 / 代码表 / ST 标记 | 一致 |
| 复权因子 | 近 20 个交易日一致；更早的尾部偏差来自窗口起点之前的分红查不到 |

## 已知边界

- `cn_stock_prefactors` 只重建策略用到的 **10 列**（`date, instrument, name, close, total_market_cap,
  float_market_cap, turn, st_status, open_days, is_sh, is_sz, is_bj`）；旧快照是 151 列。
  用到其它因子的策略（如 `ML滚动_talib.ipynb`）暂时不要切过来。
- 本地行情只覆盖切过来之后的分片（`202610`、`202611`），更长回看窗口要按 `--start` 回填。
- 基金/指数/债券表沿用旧快照，没有重建。
